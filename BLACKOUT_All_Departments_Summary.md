## IDEA-TO-MARKET WORKFLOW (5 PHASES)

### PHASE 1: DISCOVERY (48-72 hours)
**Participants:** ORACLE, SCOUT, DISCOVERY, APEX

1. **SCOUT** identifies opportunity
2. **ORACLE** validates market size >$1M
3. **DISCOVERY** confirms user willingness to pay
4. **APEX** approves go/no-go

**Output:** Approved product concept

---

### PHASE 2: VALIDATION (1-2 weeks)
**Participants:** DISCOVERY, SCOUT, LABORATORY, VAULT

1. **DISCOVERY** conducts 10+ user interviews
2. **LABORATORY** builds rapid prototype
3. **VAULT** models unit economics
4. **ORACLE** provides competitive positioning

**Output:** Validated product-market fit, financial model

---

### PHASE 3: DESIGN (1-2 weeks)
**Participants:** DESIGNER, DISCOVERY, ARCHITECT, ANALYST

1. **DESIGNER** creates wireframes and design
2. **DISCOVERY** conducts usability testing
3. **ARCHITECT** designs technical architecture
4. **ANALYST** defines success metrics

**Output:** Design approved, architecture approved, metrics defined

---

### PHASE 4: BUILD (2-4 weeks)
**Participants:** BUILDER, PIPELINE, QUALITY, OPTIMIZE, CONTENT

1. **BUILDER** + **PIPELINE** implement features
2. **QUALITY** sets up testing
3. **CONTENT** prepares launch materials
4. **HUNTER** begins pre-sales outreach

**Output:** Feature complete, tested, documented

---

### PHASE 5: LAUNCH & SCALE (1 week + ongoing)
**Participants:** DEPLOY, GROWTH, HUNTER, CLOSER, ANALYST, FRONTLINE

1. **DEPLOY** manages production rollout
2. **GROWTH** activates acquisition
3. **HUNTER**/**CLOSER** convert early customers
4. **ANALYST** tracks key metrics
5. **FRONTLINE** handles support

**Output:** Live product, customers acquired, metrics tracked
